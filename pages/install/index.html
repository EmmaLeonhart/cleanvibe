Install the organizer

For subscribers. You need the licence key and the download from your welcome page. Lost the key? Write to support@topazcomputing.com.

1. Before you start

Windows 10 or 11, with these installed:

  • Python 3.10 or newer;
  • Git for Windows;
  • the GitHub CLI, signed in with gh auth login;
  • Claude Code, signed in with your own account. Run claude once to sign in.

2. Install

Unzip cleanvibe-organizer.zip, open PowerShell in the unzipped folder, and run:

python installer\install.py --key YOUR-LICENCE-KEY

The installer checks your licence and installs cleanvibe. It creates your supervisor in Documents\GitHub\pc-manager and has it start when you sign in. To have your projects also start at boot, before anyone signs in, run it from an admin PowerShell with --boot. Add --dry-run to see the steps without changing anything.

3. Your first project

cleanvibe new my-project

Add it to pc-manager\config\logon-projects.txt, then run pc-manager ools\Add-StartupProject.ps1 my-project. From then on it starts at sign-in (and at boot, if you chose that), works through its queue, and reports what it needs from you to the supervisor.

Your account stays yours

The organizer never reads, stores or sends your Claude credentials. Usage is billed by Anthropic to your own plan or API key. cleanvibe is an independent tool, not made or endorsed by Anthropic.
