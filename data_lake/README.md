# data_lake

Raw, unprocessed artifacts dropped in as-is — the landing zone for this project.
Nothing here is refined or schema'd; it's the pool things get fished out of later.
This project is **liturgical world modelling** — source material is liturgies
(orders of service / missals) captured as photos + saved web copies, to study the
structure of worship and the discrepancies between printed and online versions.

## Contents

- `bulletin-2026-07-05-proper-14/` — full Choral Eucharist bulletin from Christ
  Church Cathedral, Vancouver (Proper 14, July 5 2026): 12 photographed pages, the
  cover-QR scan, and a saved copy of the web page that QR resolves to. See that
  folder's `index.md` for the complete liturgy outline, ministers, and provenance.
  - **Note:** the printed bulletin and the linked web page differ — capturing both is
    deliberate, so the print-vs-online discrepancies can be compared.
