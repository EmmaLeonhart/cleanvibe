# cleanvibe case studies

Real cleanvibe sessions, watched from the outside and written up: what the
session was given, what it did, what went wrong, why, and what changed in
cleanvibe as a result. They are the evidence behind cleanvibe 2's design, so
keep adding to them. When a practice or real session is started, give it a
file here, update it as the session plays out, and link the cleanvibe fix it
led to.
